Один пайплайн с пятью масками вместо трёх параллельных методов из части 1.

## Регионы и показатели

Те же три региона: МО, Краснодарский край, центр Якутии. Кавказ в этот раз включили в обучение.

- Y477110039 — Внутренние затраты на исследования и разработки
- Y477090007 — Объём отгруженных товаров обрабатывающей промышленности

## Маски

В `src/masks/` пять модулей:

- `baseline.py` — равномерное распределение по площади
- `worldpop.py` — пропорционально населению
- `regression.py` — log-регрессия на 87 регионах. Эластичность городского населения 1.39 для НИОКР, 2.77 для отгрузки
- `distance_to_city.py` — exp(-d/σ), σ=10км
- `distance_to_center.py` — exp(-d/σ), σ=30км

## Композиция

`src/masks/composition.py`: взвешенная сумма, мультипликативное гейтирование, энтропийное сглаживание. Сумма по ячейкам сохраняется.

Веса финальной композиции: regression 0.5, worldpop 0.3, distance_to_city 0.1, distance_to_center 0.1.

## Ограничения

- Муниципальных данных нет, обратная агрегация и holdout не сделаны
- CV регрессии нестабильна, R² 0.62 ± 0.22
- Не реализованы: VIIRS, ЖД, ЛЭП, базовые станции, тип территории
