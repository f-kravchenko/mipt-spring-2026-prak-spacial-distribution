# Блок 5 ТЗ: инфраструктура для высокотехнологичного развития (ИНФ12–ИНФ18)

Проведено по той же схеме, что и научно-технологический блок (README_part3, §10):
справочник в `etl/config.yaml` → ETL → `VISIBLE_INDICATORS` → веса в `COMPOSITE`.
Фронт и миграции не меняются. Все ставки (кроме ИНФ13 — счётчик) разносятся
`distribute_rate` c `rate_base: population`.

## Как закрыт каждый пункт

| Пункт | Код | Источник | Статус |
|---|---|---|---|
| ИНФ11 организации НИР | Y477110259 | паркет | было сделано ранее |
| ИНФ12 вузы на 100 тыс. | C4771005012 | Wikidata SPARQL (Q3918 + P17=Россия, регион через P131) / население Y477110373. Скрипт `scripts/build_universities_csv.py`, CSV `universities_per_100k_by_region.csv` (74 региона, 457 вузов) | прокси: головные организации, филиалы неполно; Рособрнадзор недоступен даже с RU IP |
| ИНФ13 объекты НТИ | C4771005013 | ЦКП + УНУ ckp-rf.ru (скрапинг каталогов, нужен RU VPN) + 50 ПИШ (отборы 2022/2023). Скрипт `scripts/build_ckp_csv.py`, CSV `nti_objects_by_region.csv` (73 региона, 1104 объекта) | лаборатории (Nлаб из формулы ТЗ) без единого реестра — не входят |
| ИНФ14 институты развития | — | promote.budget.gov.ru / ГИСП | **нет открытых данных**: машиночитаемого реестра с региональной привязкой не существует |

Скрипт `scripts/build_fixed_assets_csv.py`, CSV `fixed_assets_renewal_by_region.csv` (87 регионов + РФ) | готового кода по всей экономике в парке нет (есть только с/х Y477120016), поэтому из двух кодов |
| ИНФ16 степень износа ОФ | Y477110390 | паркет (87 регионов, 2024) | напрямую |
| ИНФ17 техвооружённость ИР | — | 2-наука стр. 538 | **нет открытых данных**: даже прокси отсутствует |
| ИНФ18 оборудование до 5 лет | C4771005018 | раздел «Наука» Росстата, CSV `tech_under_5_years_by_region.csv` (83 региона, собран вручную ранее) | подключён к ETL/API |

Веса в комплексной оценке — по 0.05 (экспертные наброски в
`apps/api/app/composite_config.py`), у ИНФ16 направление `inverse`. Износ/обновление
танцуют от territory/roads/power, вузы и объекты НТИ — от science-маски.

## Что ещё осталось из блока 5

- ИНФ19/23 и ИНФ2 (цифровая инфраструктура): в парке найдены коды
  Y477110164/166/167/168/169-172/260 (использование цифровых технологий, % обследованных
  организаций, 2024) — подключаются одной строкой конфига на код.
- ИНФ21 (мобильная связь): нужна связка OSM (man_made=mast) + Роскомнадзор.
- ИНФ22 (ЦОД), ИНФ31–35 (ЦКПНО-баллы, полигоны, СМЦ, ППИС, КАВФ): реестры закрыты
  или требуют ручной разметки; ИНФ36 (ОЭЗ) — короткий ручной список Минэка.
- ИНФ41–49 (загруженность инфраструктуры): только прямой запрос владельцам, данные
  не существуют в открытом контуре.

## Региональная привязка имён

Скрипты сводят названия регионов из внешних источников (Wikidata, ckp-rf.ru)
к именам паркета Росстата: `norm()` в `scripts/build_universities_csv.py`
(г. → пусто, «(без автономного округа)» срезается, короткие имена республиок —
словарём). Не сопоставились намеренно: Крым, Севастополь, ЛНР (в парке их нет).

## Запуск пересборки CSV

```
python -m scripts.build_fixed_assets_csv        # ИНФ15, из паркета
python -m scripts.build_universities_csv        # ИНФ12, Wikidata
python -m scripts.build_ckp_csv                 # ИНФ13, нужен российский IP
```

Актуальное состояние блокировок источников — в [SCRAPE_FROM_RU.md](SCRAPE_FROM_RU.md).
